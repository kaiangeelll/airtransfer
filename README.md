# 🚀 AirTransfer — Быстрая передача файлов и заметок (ПК ↔ iPhone)

Удобное веб-приложение для мгновенной передачи любых файлов (фото, 4K видео без сжатия, документы, музыка) и текста/заметок между компьютером и iPhone:
- **Через интернет (4G/LTE / из любой точки мира)** через безопасный HTTPS-туннель Cloudflare.
- **По локальной сети (домашний Wi-Fi или провод USB)**.

---

## ⚡ Как запустить (без батников или с ними)

### Вариант «Просто заходить на сайт» (Автозапуск в фоне):
1. Запусти один раз **`install_autostart.bat`**.
2. Всё! Сервер и интернет-ссылка теперь **автоматически работают в фоне при включении ПК**.
3. Никаких черных консолей и батников не открывается — ты просто открываешь сайт в браузере или на iPhone в любой момент.
*(Чтобы выключить автозапуск, запусти `uninstall_autostart.bat`)*.

### Ручной запуск:
- **`start.bat`** — запуск с открытием консоли.
- **`run_silent.vbs`** — мгновенный тихий запуск в фоне (без окон).
- **`stop.bat`** — остановка сервера и туннеля.

---

## 📱 Как подключить iPhone

1. Открой сайт на компьютере (например, `http://localhost:8000`).
2. Нажми кнопку **«Подключить iPhone»** вверху справа.
3. В открывшемся окне:
   - Вкладка **«🌍 Интернет (4G / Отовсюду)»** покажет QR-код и ссылку HTTPS от Cloudflare.
   - По этой ссылке можно заходить **с любого Айфона отовсюду** (даже через мобильный интернет на улице).
4. Наведи стандартную камеру iPhone на QR-код и открой ссылку в Safari!
5. **Лайфхак**: в Safari нажми кнопку **«Поделиться» → «На экран „Домой“»**, чтобы сайт открывался в 1 тап как приложение!

## 🌟 Основные возможности

- 🚀 **Мгновенная передача файлов**:
  - С ПК на iPhone и с iPhone на ПК.
  - Поддержка фото, видео любого разрешения (4K 60fps), документов, zip-архивов.
  - На ПК: поддержка Drag & Drop и вставки скриншотов по **Ctrl + V**.
  - На iPhone: выбор из Медиатеки, съемка на Камеру в реальном времени или выбор из приложения «Файлы».
- 📝 **База заметок и буфер обмена**:
  - Поле для заголовка и основного текста.
  - Кнопка **«Скопировать»** в один клик с визуальной анимацией.
  - Все заметки и файлы сохраняются в локальную базу данных (`data/history.db`), не пропадают при перезапуске.
- 🟢 **Онлайн-статус устройств**:
  - Автоматическое определение подключенных устройств через WebSocket (💻 ПК, 📱 iPhone).
  - Моментальное появление новых файлов и заметок без перезагрузки страницы (с приятным звуковым сигналом).
- 🔒 **Полная приватность и локальность**:
  - Файлы передаются напрямую по локальной сети без отправки на сторонние сервера или в интернет.
